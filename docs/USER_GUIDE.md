# User Guide: Crisis Cartographer

Welcome to the Crisis Cartographer, a platform for deep analytical comparison of global conflicts.

## 1. Discovering Crises
On the main dashboard, you can browse all tracked crises. Use the **Search Bar** to filter by country, cause (e.g., "ethnic"), or current status.

## 2. Comparing Two Crises
1. Select the **first crisis** from the primary dropdown.
2. Select the **second crisis** to compare it against.
3. The dashboard will automatically update with a multi-layered analysis:
    - **Narrative Insights**: AI-generated summary of structural similarities and differences.
    - **Metric Cards**: Quantitative scores for tag similarity and intensity ratios.
    - **Temporal Mapping**: Side-by-side timelines aligned to a relative starting point.
    - **Geospatial Map**: Visualization of regional impact zones.
    - **Relational Network**: Connections to other similar historical events.

## 3. Understanding Predictions
The **Predictive Synthesis** section provides a 12-month projection for casualties and displacement.
- **Trend**: Look for "Escalating" or "Decline" flags.
- **Confidence**: High confidence scores indicate stable historical patterns, while low scores suggest high volatility or data gaps.

## 4. Exporting Data
Click the **"Export Report"** button in the comparison view to download a full JSON analytical summary. This is ideal for researchers and policy analysts who need to integrate the data into other tools.
